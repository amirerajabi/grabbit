Browser extensions for Chrome, Edge and Firefox, and two fixes.

If you have Grabbit 1.0.0, it updates itself: on Windows and Linux, wait for **Restart to update** in the status bar
(or choose **Check for updates** in Options → Updates).

### Downloads

- **Windows:** `Grabbit-Setup-1.0.1.exe`
- **macOS (Apple silicon):** `Grabbit-1.0.1-mac-arm64.dmg`
- **Linux:** `Grabbit-1.0.1-x86_64.AppImage`
- **Browser extensions:** `Grabbit-Extension-Chrome-1.0.1.zip`, `Grabbit-Extension-Edge-1.0.1.zip` and
  `Grabbit-Extension-Firefox-1.0.1.zip`. See
  [how to install them](https://github.com/amirerajabi/grabbit/blob/main/docs/browser-extensions.md).

### New: browser extensions

One extension for Chrome, Edge and Firefox, like IDM's:

- **Download with Grabbit** in the right-click menu of links, images, video and audio.
- **Download selected links with Grabbit** and **Download all links with Grabbit**. The links open in the Batch
  dialog, filtered to links to files, so you can pick what to download.
- Browser downloads of the file types Grabbit captures are handed to Grabbit, with your cookies, so downloads that
  need a sign-in still work.
- The toolbar popup shows whether Grabbit is running and turns capturing on or off.

The extensions talk only to the Grabbit app on your computer. Nothing is sent anywhere else
([privacy policy](https://github.com/amirerajabi/grabbit/blob/main/docs/PRIVACY.md)).

### Fixes

- Changing several settings quickly could stop the download engine. Settings are now saved one at a time, and a failed
  save no longer takes the engine down.
- The app now answers the browser extension correctly in Chrome and Edge, so browser downloads are taken over. You need
  this version of the app for that; with 1.0.0, only the right-click menu works.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
