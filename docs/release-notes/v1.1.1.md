Videos from web pages, a site grabber, FTP and SFTP, archive extraction, proxies, site logins, checksums and "shut down
when done".

If you have an earlier Grabbit, it updates itself: on Windows and Linux, wait for **Restart to update** in the status
bar (or choose **Check for updates** in Options → Updates).

### Downloads

- **Windows:** `Grabbit-Setup-1.1.1.exe`
- **macOS (Apple silicon):** `Grabbit-1.1.1-mac-arm64.dmg`
- **Linux:** `Grabbit-1.1.1-x86_64.AppImage`
- **Browser extensions:** `Grabbit-Extension-Chrome-1.1.1.zip`, `Grabbit-Extension-Edge-1.1.1.zip` and

### New

- **Videos from web pages.** Paste a YouTube, Vimeo or other video page into **Add URL** and choose the quality, or
  audio only, with the size shown for each. Grabbit uses [yt-dlp](https://github.com/yt-dlp/yt-dlp), which knows about
  1,800 sites. It is downloaded the first time you need it (about 18 MB) and kept up to date. FFmpeg joins the video
  and audio tracks: Grabbit uses your copy if you have one, or downloads it. For other web pages, choose **Look for a
  video on it**. In the browser, right-click a page or a video and choose **Download video with Grabbit**.
- **Site grabber.** **Batch → Website** reads a page, and the pages it links to (up to three levels deep), and lists
  the files of the types you choose, ready to download. **Stay on this site** keeps it from wandering off.
- **FTP and SFTP.** `ftp://` and `sftp://` addresses download with several connections and resume, like web downloads.
  SFTP logs in with a password, your SSH agent or your key, and warns if a server's host key changes.
- **Archive extraction.** ZIP, 7z and RAR files can be extracted when they finish, into a folder next to them
  (Options → After download, or per download in the Add dialog). Multi-part archives are extracted once every part is
  in. For password-protected archives, Grabbit tries your saved passwords or asks for one. 7-Zip is downloaded on first
  use unless you have it installed.
- **Proxy.** Options → Connection: your system proxy, or an HTTP or SOCKS5 proxy (with a login if needed), plus
  addresses that skip it.
- **Site logins.** When a site asks for a username and password (HTTP Basic or Digest), Grabbit asks you and can save
  it, encrypted. Manage them in Options → Site logins.
- **Checksums.** Paste an MD5, SHA-1, SHA-256 or SHA-512 hash in the Add dialog and Grabbit checks the file when it
  finishes. You can also calculate a hash for any finished file in the details pane.
- **When done.** Quit Grabbit, sleep, hibernate or shut down when all downloads finish (status bar → When done), after
  a one-minute warning you can cancel.
- **Virus scan and open when done.** Scan finished files with Microsoft Defender or a scanner you choose, and open a
  file automatically when it finishes.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
