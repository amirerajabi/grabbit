The first release of Grabbit, an IDM-style download manager for Windows, macOS and Linux.

### Downloads

- **Windows:** `Grabbit-Setup-1.0.0.exe`
- **macOS (Apple silicon):** `Grabbit-1.0.0-mac-arm64.dmg`
- **Linux:** `Grabbit-1.0.0-x86_64.AppImage`

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.

### Highlights

- Segmented downloading: up to 32 connections per file. When a connection finishes, it takes over half of the largest
  part still downloading.
- Pause and resume, including after a restart. Servers without resume support fall back to a single connection.
- Expired links can be replaced in Properties, keeping the bytes already downloaded.
- Queues with a scheduler (start and stop times, days of the week) and a files-at-once limit.
- A global speed limiter and a limit per download.
- Categories with their own folders, batch downloads with `*` wildcard patterns, and renaming of duplicates.
- Clipboard monitoring, a tray icon, notifications and taskbar progress.
- A browser extension (the `extension/` folder) that sends links and browser downloads to Grabbit.
- Automatic updates from GitHub Releases: on Windows and Linux new versions download in the background and install
  with **Restart to update**. On macOS the app shows the new version with a link.
- Light and dark themes, a command palette (Ctrl+K) and keyboard shortcuts.
