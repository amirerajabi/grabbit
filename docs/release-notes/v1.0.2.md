Links from your browser now pop up over the browser.

If you have Grabbit 1.0.0 or 1.0.1, it updates itself: on Windows and Linux, wait for **Restart to update** in the status
bar (or choose **Check for updates** in Options → Updates).

### Downloads

- **Windows:** `Grabbit-Setup-1.0.2.exe`
- **macOS (Apple silicon):** `Grabbit-1.0.2-mac-arm64.dmg`
- **Linux:** `Grabbit-1.0.2-x86_64.AppImage`
- **Browser extensions:** `Grabbit-Extension-Chrome-1.0.2.zip`, `Grabbit-Extension-Edge-1.0.2.zip` and
  `Grabbit-Extension-Firefox-1.0.2.zip`. See
  [how to install them](https://github.com/amirerajabi/grabbit/blob/main/docs/browser-extensions.md). The extensions
  themselves haven't changed since 1.0.1, so an installed one keeps working.

### Fixes

- **The Add dialog now comes to the front.** When you sent a link from the browser extension, or copied a download
  link, Grabbit opened the Add dialog in a window that stayed in the tray or behind your browser, and you had to open
  Grabbit to see it. Now the window comes up over the browser, like IDM's download dialog. If Windows keeps the
  keyboard with the app you're typing in, the dialog is still on top and Grabbit's taskbar button flashes until you
  click it.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
