Grabbit can now start with Windows, so it is ready to catch downloads right after you sign in.

If you have an earlier Grabbit, it updates itself: on Windows and Linux, wait for **Restart to update** in the status
bar (or choose **Check for updates** in Options → Updates).

### Downloads

- **Windows:** `Grabbit-Setup-1.2.0.exe`
- **macOS (Apple silicon):** `Grabbit-1.2.0-mac-arm64.dmg`
- **Linux:** `Grabbit-1.2.0-x86_64.AppImage`
- **Browser extensions:** `Grabbit-Extension-Chrome-1.2.0.zip`, `Grabbit-Extension-Edge-1.2.0.zip` and
  `Grabbit-Extension-Firefox-1.2.0.zip`. See
  [how to install them](https://github.com/amirerajabi/grabbit/blob/main/docs/browser-extensions.md). This release has
  no extension changes; keep whatever version you have.

### New

- **Start with Windows.** Options → General → **Start Grabbit when Windows starts**. Grabbit comes up quietly in the
  tray (no window in the way), watching the clipboard and ready for links from your browser. Turn it off there, or
  any time from Task Manager like any other startup program.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
